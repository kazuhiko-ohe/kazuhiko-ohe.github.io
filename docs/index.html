このデータの作成は、厚生労働行政推進調査事業費補助金 地域医療基盤開発推進研究事業 ICD11対応標準病名マスターの構造と作成に関する研究 （25IA2013 令和7-8年度）（研究代表者：大江和彦（順天堂大学））により実施されており、その作業の途中報告として公表し、仕様やコードについてご意見を募集するものです。

現時点では、各病名に振られているICD11コード、およびそれに関する情報は、不正確であったり、データ形式に仕様案と異なるなどの不備がある可能性があります。

また、ICD11は分類コードであり、かならずしも全ての標準病名に対して、ただ一つのICD11コードを割り当てることができるとは限らないため、本来のICD11コードの記述方法とは異なる記述方法をとっていることもあります。

今後、「ICD10対応標準病名マスター」を提供している、（一財）医療情報システム開発センター（MEDIS-DC）から公表する計画がありますが、その時期、公表方法はまだ確定していませんので、それに関する同財団へのお問い合わせはご遠慮ください。
